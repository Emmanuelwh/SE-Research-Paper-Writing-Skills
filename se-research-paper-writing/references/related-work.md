# Related Work Writing Guide

## Goal

Write Related Work as positioning, not as a list of citations. The section should explain what prior research or practice has established, where it falls short, and how this paper differs.

## Recommended Structure

1. Related problem domain: papers studying the same SE task or phenomenon.
2. Related techniques/tools: methods that solve similar tasks with different assumptions.
3. Related empirical evidence: datasets, taxonomies, benchmarks, surveys, or prior studies.
4. Closest work comparison: explicitly contrast with the most similar papers.

## Writing Pattern

For each related-work group:

1. Topic sentence: define the group.
2. Synthesis: summarize shared goals, methods, assumptions, or findings.
3. Limitation: explain what remains missing relative to this paper.
4. Positioning: state how this paper differs or complements the group.

## Tool Paper Positioning

Emphasize differences in task scope, input evidence, assumptions, workflow support, technical design, evaluation setting, and practical deployment.

## Empirical Study Positioning

Emphasize differences in research questions, data sources, taxonomy, sampling, labels, study scale, analysis method, and implications.

## Checklist

1. Are related papers grouped by idea rather than listed one by one?
2. Does each group end with clear positioning?
3. Are closest papers compared fairly and specifically?
4. Does the section avoid claiming novelty by ignoring adjacent work?
5. Does the related-work gap match the Introduction gap?
